Written by the API server started with --dashboard <folder> (sci_jepa/api/calllog.py). The page shows the latest calls of each server; health, ready, metrics and docs requests are kept apart so load-balancer polls do not push real calls out. Every call is also appended to apicalls/log/<server>/<day>.jsonl next to this page (full history, not pushed to the hosted site). Bodies above 24 KB are cut on this page; the JSONL keeps up to 256 KB. Authorization headers and cookies are never logged. The request text is what users typed: the server's --call-log-redact setting (shown in the cards) says whether it is kept as sent, with emails and phone numbers removed, or not at all.
